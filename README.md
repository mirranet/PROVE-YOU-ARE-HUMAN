## О проекте

**PROVE YOU ARE HUMAN** — это браузерная система проверки пользователя с помощью обычной веб-камеры.

Вместо CAPTCHA с текстом или изображениями система просит пользователя выполнить несколько физических действий перед камерой.

Например:

* поднять правую руку;
* поднять левую руку;
* показать 3 пальца;
* сжать руку в кулак;
* показать открытую ладонь;
* повернуть голову влево/вправо;
* наклонить голову;
* открыть рот.

Все движения распознаются **в реальном времени непосредственно в браузере**.

> Проект демонстрирует взаимодействует с камерой и системой верификации, а не является научным доказательством того, что пользователь является человеком.

## Челленджи

В текущей версии реализованы **10 типов заданий**:

| Challenge             | Recognition     |
| --------------------- | --------------- |
| Raise your right hand | Hand tracking   |
| Raise your left hand  | Hand tracking   |
| Show three fingers    | Finger counting |
| Make a fist           | Finger counting |
| Open your palm        | Finger counting |
| Look left             | Face tracking   |
| Look right            | Face tracking   |
| Tilt your head left   | Face tracking   |
| Tilt your head right  | Face tracking   |
| Open your mouth       | Face tracking   |

## Error Mode

Одна из основных особенностей проекта — система не просто сообщает об ошибке, а даёт **конкретную подсказку пользователю**.

Например:

```text
ERROR

Turn your head to the left.
```

или:

```text
ERROR

Open your mouth.
```

Для жестов с пальцами система может определить фактическое количество пальцев и использовать его для обратной связи.

Цель — сделать взаимодействие понятным даже при неточном движении.

## Интерфейс

Интерфейс показывает:

* live camera feed;
* визуализацию костей;
* текущее задание;
* прогресс проверки;
* состояние отслеживания рук;
* состояние отслеживания лица;
* состояние движения;

```text

```

# Локальный запуск

## Requirements

* Node.js 18+
* современный браузер;
* веб-камера.

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/YOUR_USERNAME/prove-you-are-human.git
cd prove-you-are-human
```

### 2. Установите зависимости

```bash
npm install
```

### 3. Запустите сервер разработки

```bash
npm run dev
```

После запуска Vite покажет локальный адрес:

```text
http://localhost:5173/
```

Откройте его в браузере и разрешите доступ к камере.

### Главные модули

**`camera/`**
Отвечает за получение данных с камеры и работу MediaPipe.

**`recognition/`**
Преобразует landmarks в конкретные жесты и движения.

**`verification/`**
Содержит список challenges и проверяет правильность выполнения.

**`main.js`**
Связывает камеру, распознавание, verification logic и интерфейс.

# Конфиденциальность

Обработка движений выполняется в браузере.

Камера используется для распознавания в режиме реального времени во время прохождения проверки.

Проект не требует регистрации пользователя или установки отдельного приложения.
